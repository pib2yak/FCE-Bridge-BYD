DISCLOSURE: This is an AI-generated project. Use at your own risk.

Makes BYD's media app treat a renamed Auxio / Retro build as a partner music app,
so it shows on the home-screen media widget and the driver's display.

| Helper package | Player package it bridges |

| com.fce.onlinemedia.tidal | com.aspiro.tidal (renamed Auxio) |
| com.fce.onlinemedia.deezer | deezer.android.app (renamed Retro) |
